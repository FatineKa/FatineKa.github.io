# Portfolio

Personal portfolio site for Fatine Kassabi. Plain HTML/CSS, no build step.

## Deploy to GitHub Pages

1. Create a new repository on GitHub (e.g. `portfolio` or `FatineKa.github.io`).
2. Push this folder to it:
   ```
   git remote add origin https://github.com/FatineKa/<repo-name>.git
   git add .
   git commit -m "Initial portfolio site"
   git push -u origin main
   ```
3. On GitHub: repo Settings → Pages → Source → set to `main` branch, `/ (root)` folder → Save.
4. The site will be live at `https://fatineka.github.io/<repo-name>/`
   (or `https://fatineka.github.io/` if the repo is named `FatineKa.github.io`).
